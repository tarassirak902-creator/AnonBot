# Анонимные вопросы — этап 1

Добавлено:

- персональный `question_token` для каждого пользователя;
- deep-link `https://t.me/<bot>?start=ask_<token>`;
- стандартное приветствие CASPER с персональной inline-кнопкой;
- отдельная ветка обращения с нижней клавиатурой;
- отправка текстового анонимного вопроса;
- раздел «Вопросы» в главном меню;
- список вопросов по номеру и дате;
- просмотр вопроса и текстовый ответ;
- личная ссылка и базовая статистика переходов/вопросов;
- уведомление о вопросе во время активного анонимного диалога без показа текста;
- автоматические миграции базы при запуске.

Пока оставлены заглушки:

- подарки из ветки вопросов;
- подарочный VIP;
- платное раскрытие автора;
- расширенная админская статистика.

Перед запуском:

1. Сделать резервную копию `data/bot.db`.
2. Запустить на тестовом токене и копии базы.
3. Проверить обычный `/start`, `/start ask_...`, отправку и ответ на вопрос.
4. Только после проверки переносить на активного бота.
