# Анонимные вопросы — этап 2

## Что изменено

- В раздел «❓ Вопросы» добавлена отдельная фирменная обложка `app/assets/brand/questions.png`.
- Раздел теперь показывает число новых вопросов и новых ответов.
- Добавлен экран «💬 Ответы на мои вопросы» со списком только по номеру и дате.
- Полный текст ответа открывается только в карточке ответа.
- Ответы больше не показываются поверх активного анонимного диалога.
- Во время диалога приходит только короткое уведомление, а после его завершения — итоговое уведомление с кнопкой открытия вопросов.
- В «Моей ссылке» добавлена инструкция «📖 Как установить в профиль».
- Кнопка копирования ссылки отсутствует: ссылка уже доступна в тексте.
- При нулевом числе переходов показывается подсказка о размещении ссылки в профиле.
- Добавлена одноразовая рассылка о новой функции: `tools/send_questions_intro.py`.
- Настройки вопросов не добавлялись.

## Обновление на сервере

1. Остановите бота.
2. Создайте резервную копию файла базы данных.
3. Замените файлы проекта файлами из архива.
4. Сохраните свой рабочий `.env` и действующую базу данных — не заменяйте их пустыми файлами из архива.
5. Запустите бота. Новые столбцы базы создадутся автоматически.
6. Проверьте основной функционал на тестовом аккаунте.

## Одноразовое уведомление пользователям

Рассылка не запускается автоматически. После проверки обновления выполните из корня проекта:

```bash
python tools/send_questions_intro.py
```

Скрипт помечает только успешно уведомлённых пользователей. При повторном запуске он не отправит сообщение им ещё раз.

## Основные проверки

- Открытие раздела «❓ Вопросы» показывает новую картинку.
- Новый вопрос во время диалога не раскрывается, после завершения диалога появляется итоговое уведомление.
- Новый ответ во время диалога не раскрывается, после завершения диалога появляется итоговое уведомление.
- «Ответы на мои вопросы» показывает номер и дату.
- Открытие ответа отмечает его прочитанным.
- Подсказка в «Моей ссылке» исчезает после первого перехода.
- Обычный `/start`, поиск собеседника, игры и профиль работают как раньше.
