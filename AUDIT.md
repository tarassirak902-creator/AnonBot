# Аудит AnonBot

Рабочая ветка: `agent/full-project-audit`.

## Исправлено

- Удалена рабочая SQLite-база из контроля версий.
- Расширен `.gitignore` для секретов, баз данных, логов, кэшей и виртуальных окружений.
- Убраны реальные Telegram ID из значений конфигурации по умолчанию.
- Добавлена строгая проверка обязательных переменных окружения.
- Скрипт запуска больше не устанавливает зависимости при каждом старте.
- Systemd unit использует `.env`, системный Python и более безопасные ограничения.
- Ограничен неограниченный рост кэша anti-flood middleware.
- Добавлена проверка Telegram Stars до подтверждения оплаты.
- Добавлен GitHub Actions workflow для установки зависимостей, `pip check`, компиляции и smoke-import.
- Добавлен единый ledger Telegram-платежей по `telegram_payment_charge_id`.
- Повторные, конфликтующие и прерванные платежи больше не исполняются автоматически повторно.
- Ошибки платёжных обработчиков сохраняются в ledger для ручной сверки вместо удаления claim.
- Добавлены регрессионные тесты на дубли, сбои и конфликт метаданных платежа.

## Выявлено и проверяется далее

- Атомарность бизнес-операций после получения платежа: начисление услуги, статистика и запись покупки пока выполняются отдельными вызовами.
- Ручный процесс сверки записей ledger с `failed_at` и незавершённым статусом.
- Гонки при создании/принятии дуэлей и matchmaking.
- Широкие `except Exception` без достаточного логирования.
- Долгоживущие глобальные словари временного состояния.
- Крупные модули `repository.py`, `questions.py`, `advertising.py` и административные callbacks.
- SQL-индексы и транзакционные границы SQLite.

Этот документ обновляется по мере прохождения аудита.
