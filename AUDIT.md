# Аудит AnonBot

Рабочая ветка: `agent/full-project-audit`.

## Исправлено

- Удалена рабочая SQLite-база из контроля версий и усилен `.gitignore`.
- Добавлена строгая проверка конфигурации, безопасный Linux/systemd запуск и ограничение служебных кэшей.
- Добавлены CI, smoke-import и регрессионные тесты.
- Все Telegram-платежи защищены единым ledger по `telegram_payment_charge_id`.
- Stars, VIP, подарки, раскрытие автора и расчёты дуэлей выполняются атомарно.
- Telegram Premium использует двухфазную доставку pending/delivering/delivered/failed без автоматического опасного повтора.
- Инициализация базы маршрутизируется через версионный миграционный фасад без потери очередей и активных диалогов.
- Matchmaking выполняется одной транзакцией, не создаёт пересекающиеся пары и исключает заблокированных пользователей.
- Первая оплаченная ставка дуэли создаётся атомарно только при существующем взаимном диалоге.
- Один charge ID и одна пара пользователей не могут создать несколько waiting/active дуэлей.
- Добавлены индексы для вопросов, посещений, покупок, платёжного ledger, Premium и дуэлей; миграция пропускает индексы, если ленивые колонки ещё отсутствуют.
- Критичные обработчики внешних уведомлений журналируют ошибки вместо молчаливого повторения бизнес-операций.
