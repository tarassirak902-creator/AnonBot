# Security policy

## Reporting

Не публикуйте токены бота, содержимое `.env`, рабочие базы SQLite и персональные данные пользователей в issues или pull requests.

При утечке `BOT_TOKEN` немедленно отзовите токен через BotFather и замените его на сервере.

## Repository hygiene

В Git не должны попадать:

- `.env` и другие файлы с секретами;
- `data/*.db`, `*.sqlite`, `*.sqlite3`;
- логи;
- виртуальные окружения;
- резервные копии рабочей базы.
